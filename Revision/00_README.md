## Priority philosophy

Do **not** spend equal time on every technology. The target role is data engineering, so prioritize:

1. Python
2. SQL
3. Snowflake
4. PySpark
5. Projects P1/P2
6. Microsoft Fabric
7. Cloud/data-engineering fundamentals
8. Git/SDLC
9. Scala

Each technical section uses the same structure where possible:

**Curriculum Notes → Interview Q&A → Example → Interview Point → Scenario**

The source-derived Q&A from the uploaded PySpark, Scala, Snowflake and Fabric documents is retained rather than replaced with a shorter summary.

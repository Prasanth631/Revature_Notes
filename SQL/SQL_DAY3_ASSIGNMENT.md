### 🟢 Part A: Subquery Exercises

#### Q1: Products whose price > average product price
```sql
SELECT * FROM Products 
WHERE price > (SELECT AVG(price) FROM Products);
```
* **What is this query?** Single-row scalar subquery statement.
* **What does it do?** Finds products priced higher than the overall catalog average.
* **How keyword works:** `(SELECT AVG(price) FROM Products)` evaluates to a single numeric value passed into the `WHERE price >` comparison.

#### Q5: Second highest priced product
```sql
SELECT * FROM Products 
WHERE price = (
    SELECT MAX(price) FROM Products 
    WHERE price < (SELECT MAX(price) FROM Products)
);
```
* **What is this query?** Nested maximum subquery statement.
* **What does it do?** Finds the product with the second highest price (65000 is max; 18000 is 2nd max).
* **How keyword works:** Inner subquery finds max price; middle subquery finds max price below overall max; outer query fetches matching product.

#### Q9: Products whose price > EVERY Stationery product (`> ALL`)
```sql
SELECT * FROM Products 
WHERE price > ALL (SELECT price FROM Products WHERE category = 'Stationery');
```
* **What is this query?** Quantified `> ALL` subquery.
* **What does it do?** Selects products priced higher than the maximum price in the 'Stationery' category (Notebook is 120).
* **How keyword works:** `> ALL(list)` requires condition to be TRUE for every item in the returned list.

### 🔵 Part B: Aggregate Functions with JOIN

#### Q12: Total sales amount for each product (`Price * Quantity`)
```sql
SELECT p.product_name, IFNULL(SUM(p.price * o.quantity), 0) AS total_sales_amount
FROM Products p
LEFT JOIN Orders o ON p.product_id = o.product_id
GROUP BY p.product_id, p.product_name;
```
* **What is this query?** Multi-table join aggregation query.
* **What does it do?** Calculates total monetary revenue generated by each product.
* **How keyword works:** `SUM(p.price * o.quantity)` multiplies product price by order quantity and sums the revenue per product group.

#### Q20: Products whose total ordered quantity > 5
```sql
SELECT p.product_name, SUM(o.quantity) AS total_qty
FROM Products p
JOIN Orders o ON p.product_id = o.product_id
GROUP BY p.product_id, p.product_name
HAVING SUM(o.quantity) > 5;
```
* **What is this query?** Grouped aggregation filtering query.
* **What does it do?** Displays products with a cumulative ordered quantity exceeding 5 units.
* **How keyword works:** `HAVING SUM(o.quantity) > 5` filters product groups AFTER sum aggregation completes.

### 🟡 Part C: Database Views

#### Q22: OrderSummary View
```sql
CREATE OR REPLACE VIEW OrderSummary AS
SELECT o.customer_name, p.product_name, o.quantity, o.order_date, o.city
FROM Orders o
JOIN Products p ON o.product_id = p.product_id;
```
* **What is this query?** DDL View creation query linking relational tables.
* **What does it do?** Creates a reusable virtual view `OrderSummary` combining order and product info.
* **How keyword works:** `CREATE OR REPLACE VIEW` saves query definition in database catalog.

### 🔴 Part D: Advanced Analytical Queries & Views

#### Q30: View for Monthly Sales Reports
```sql
CREATE OR REPLACE VIEW MonthlySalesReport AS
SELECT 
    DATE_FORMAT(o.order_date, '%Y-%m') AS sales_month,
    COUNT(o.order_id) AS total_orders,
    SUM(o.quantity) AS total_quantity_sold,
    SUM(p.price * o.quantity) AS monthly_revenue
FROM Orders o
JOIN Products p ON o.product_id = p.product_id
GROUP BY DATE_FORMAT(o.order_date, '%Y-%m');
```
* **What is this query?** DDL Monthly reporting view query.
* **What does it do?** Aggregates orders, item quantities, and total revenue grouped by sales month (`YYYY-MM`).
* **How keyword works:** `DATE_FORMAT(o.order_date, '%Y-%m')` groups transaction dates into monthly buckets.

#### Q32: Customers whose purchase amount > average customer purchase amount
```sql
WITH CustomerTotals AS (
    SELECT customer_name, SUM(p.price * o.quantity) AS total_spend
    FROM Orders o
    JOIN Products p ON o.product_id = p.product_id
    GROUP BY customer_name
)
SELECT customer_name, total_spend 
FROM CustomerTotals
WHERE total_spend > (SELECT AVG(total_spend) FROM CustomerTotals);
```
* **What is this query?** CTE with subquery average comparison statement.
* **What does it do?** Calculates total spend per customer in `CustomerTotals` CTE, then filters customers spending above the average customer spend.
* **How keyword works:** `WITH CustomerTotals AS (...)` prepares customer spending totals for subsequent average calculation.
